{{N}}.3 状态详细说明

Created

初始状态。对象已创建但未初始化。此状态下只能调用 init()， 调用其他方法会 [行为]。

内部变量：[如"config = null, workers = []"]

Ready

就绪状态。所有资源已初始化，可以接受 process() 调用。 这是系统的稳态，大部分时间应该处于此状态。

内部变量：[如"config = loaded, workers = pool.size()"]

Processing

处理中状态。此状态下系统正在执行业务逻辑，资源被占用。 并发调用 process() 会 [行为：排队/拒绝/覆盖]。

内部变量：[如"currentTask = task, startTime = Date.now()"]

Failed

失败状态。可以通过 retry() 恢复到 Ready（如果重试次数未超限）， 或通过 destroy() 进入终态。

内部变量：[如"error = lastError, retryCount = N"]

非法转换

以下转换是非法的，调用会 [抛出 StateError / 被忽略 / 排队等待]：

  • Created -> Processing：必须先 init()
  • Failed -> Processing：必须先 retry()
  • Destroyed -> 任何状态：终态不可逆
