{{N}}.2 核心配置参数

服务器配置

参数类型默认值取值范围说明不当值后果
port number 3000 1-65535 监听端口 [如"<1024 需要 root 权限；已被占用时启动失败"]

数据配置

参数类型默认值取值范围说明不当值后果
database.url string "sqlite://data.db" 连接字符串 数据库连接 [如"格式错误启动时报连接失败"]
cache.ttl number 300 0-86400 缓存过期时间(秒) [如"0 = 禁用缓存；过大会导致数据陈旧"]
cache.maxSize number 1000 1-100000 缓存最大条目数 [如"过大会占用过多内存；过小会频繁淘汰"]

日志配置

参数类型默认值取值范围说明不当值后果
log.level string "info" debug/info/warn/error 日志级别 [如"debug 在生产环境会产生大量日志，影响性能"]
log.format string "json" json/text 日志格式 [如"text 格式不适合日志聚合系统解析"]

{{N}}.3 配置示例

以下是一个完整的生产环境配置示例：


# config.production.yaml
# 生产环境配置 — 所有参数都有注释说明

server:
  port: 8080              # 监听端口
  host: "0.0.0.0"         # 监听所有网卡
  workers: 4              # 等于 CPU 核数
  timeout: 30000          # 请求超时 30s

database:
  url: "postgres://user:pass@db-host:5432/mydb"
  pool:
    min: 5                # 最小连接数
    max: 20               # 最大连接数
    idle: 10000           # 空闲连接超时 10s

cache:
  ttl: 300                # 缓存 5 分钟
  maxSize: 5000           # 最多 5000 条
  backend: "redis"        # 使用 Redis 作为缓存后端

log:
  level: "info"           # 生产环境用 info
  format: "json"          # JSON 格式便于日志系统采集
  output: "stdout"        # 输出到 stdout，由容器运行时收集
Sources: [config-file]:[1-50] [defaults-file]:[1-30]

{{N}}.6 常见配置陷阱

陷阱 1：环境变量覆盖

环境变量 APP_PORT 会覆盖配置文件中的 port。 如果同时设置了两者，以环境变量为准。调试时容易忘记检查环境变量。

陷阱 2：配置文件路径

配置文件的默认路径是相对于工作目录，不是相对于可执行文件。 从不同目录启动会读取不同的配置文件。

陷阱 3：类型转换

环境变量都是字符串。如 APP_WORKERS="4" 会被正确转为数字， 但 APP_WORKERS="four" 会静默回退到默认值，不报错。
