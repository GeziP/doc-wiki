{{N}}.3 Error Propagation Path

Tracing TimeoutError from origin to final handling:


Store.read(key) -- timeout --> TimeoutError
  -- caught by CacheLayer --> retry 3x (backoff: 100ms, 200ms, 400ms)
    -- all failed --> wrap as DependencyError(Store unavailable)
      -- caught by BusinessLayer --> log warn
        -- return degraded result (stale data from L1 cache)
          -- if L1 empty --> return ErrorCode.E005 to caller
Design Decision

Chose degradation over hard failure because brief read unavailability should not block entire requests.
