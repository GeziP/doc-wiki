{{N}}.3 数据变换详情

以下是每个阶段的数据结构变化，展示字段的增删改：

阶段 1 输出：ParsedMsg


{
  "id": "msg_123",           // 来自输入 JSON
  "type": "request",         // 来自输入 JSON
  "payload": { ... },        // 来自输入 JSON，未经校验
  "timestamp": 1234567890,   // 解析时添加，来自 Date.now()
  "_raw": "..."              // 原始字符串，用于日志
}

阶段 2 输出：ValidMsg


{
  "id": "msg_123",
  "type": "request",
  "payload": { ... },        // 已校验，类型已转换
  "timestamp": 1234567890,
  "_validation": {           // 校验元数据
    "passed": ["id", "type", "payload"],
    "warnings": ["payload.size 接近上限"]
  }
  // _raw 已移除（安全考虑）
}
设计决策

在校验阶段移除 _raw 字段是出于安全考虑：原始字符串可能包含 未转义的用户输入，在后续处理中存在注入风险。
